¿Qué es JavaScript?

JavaScript es un lenguaje de programación que se utiliza para crear páginas y aplicaciones web interactivas. Es un
lenguaje de programación que se utiliza para crear contenido web dinámico, como elementos interactivos, formularios,
menús e incluso juegos.

A diferencia de HTML y CSS, que se encargan de la estructura y el estilo visual respectivamente, JavaScript
permite que una página reaccione a las acciones del usuario, como hacer clic en un botón, mover el cursor o enviar un formulario.


Creado en 1995, JavaScript ha evolucionado hasta convertirse en una herramienta fundamental tanto del lado del cliente (es decir, en el navegador del usuario)
como del lado del servidor, gracias a entornos como Node.js. Se caracteriza por ser un lenguaje de tipado dinámico, lo que significa que no es necesario definir el
tipo de las variables, y por su enfoque orientado a eventos, lo que le permite responder a distintas acciones en tiempo real.
